# CB-TimeSense: Automatic Circuit Breaker Closing Time Estimation

**Автоматическое определение времени включения выключателя для АПВ с Улавливанием Синхронизма**

---

## Концепция

Функция **улавливания синхронизма** в АПВ требует точного значения времени включения выключателя `T_close` (от подачи команды до появления тока). Сейчас этот параметр вводится вручную из паспорта, что ведёт к ошибкам из-за деградации механики, человеческого фактора и неточности паспортных данных.

**Решение:** автоматически измерять `T_close` из данных COMTRADE-осциллографирования (дискретный сигнал команды + аналоговый ток от ТТ) и строить предиктивную модель для следующей операции (N+1).

## Алгоритм детектирования T_close

```
1. Найти дискретный канал команды на включение (CLOSE / КВ / 52C / CMD)
2. Найти аналоговые токовые каналы (IA, IB, IC; единицы: А)
3. t_command = момент фронта 0→1 команды
4. Огибающая: I_env = max(|IA|, |IB|, |IC|)
5. Порог: threshold = 5% от max(I_env)
6. t_current = первый момент устойчивого превышения порога (≥ 3 отсчёта)
7. T_close = (t_current - t_command) × 1000  [мс]
```

### Обработка граничных случаев

Двухпроходная фильтрация выбросов:

| Ситуация | Условие | Метка | Действие |
|---|---|---|---|
| Залипание выключателя (абс.) | Ток не появился за 2000 мс | `FAILED` | Из обучения исключается |
| Залипание / аномалия (адапт.) | T_close > median × 1.5 | `OUTLIER` | Из обучения исключается |
| Шум ТТ | Пик тока < 5% max или < N_sustain отсчётов | Игнорируется | — |
| Нет канала команды | Канал CLOSE/КВ/52C не найден | `ESTIMATED` | Используется с пониженным весом |
| Физически нереальное (малое) | T_close < 10 мс | `OUTLIER` | Из обучения исключается |
| Предсуществующий ток | Ток > порога до команды | `AMBIGUOUS` | Только в train, не в test |

Адаптивный порог автоматически охватывает все типы выключателей:
- Вакуумные (ВВ/TEL): 30–80 мс
- Элегазовые (ГВШ, HPL): 50–150 мс
- Маломасляные (МКП, ВМПЭ): 80–300 мс
- Старые масляные (деградировавшие): 300–1000 мс

## Модели предсказания

| Модель | MAE (мс) | Дрейф | Выбросы |
|---|---|---|---|
| Медиана (W=10) | ~2.8 | - | + |
| EWMA (α=0.25) | ~3.1 | частично | частично |
| **Калман (рекомендован)** | **~1.9** | + | + гейтинг |
| Тейл-Сен | ~2.2 | + | + |

**Фильтр Калмана** — основная рекомендация для production:
- Явно моделирует механический дрейф (вектор состояния: [T_close, скорость_дрейфа])
- Даёт доверительный интервал → консервативная уставка `T_setpoint = T_pred + 2σ`
- Инновационный гейтинг автоматически отклоняет залипания и аномалии ТТ

## Уставка для АПВ

```python
pred_ms, std_ms = kalman_model.predict_with_uncertainty()
T_setpoint = pred_ms + 2 * std_ms  # 95% доверительный интервал
```
